## Description
A large international retail chain wants to understand its performance across regions, product categories and time periods. This project performs exploratory data analysis on their sales data to uncover insights that drive business decisions.
### Features
- Data import
- Data cleaning
- Basic data analyses
- Data visualisation
- Insights and recommendations

## Dataset
The data are drawn from the "Global Superstore Dataset" on Kaggle (https://www.kaggle.com/datasets/apoorvaappz/global-super-store-dataset)
The dataset has 24 columns and 1000 rows
##### Cleaning
Cleaning is included in the main project jupyter notebook. Includes handling missing data and correct handling of datetime values.

## Installation
Clone the repository:
- git clone https://github.com/Olly-W/GlobalMart-Python.git
Navigate to the project folder:
- cd GlobalMart-Python
Install dependencies:
- install Python 3.x
- pip install pandas
- pip install numpy
- pip install matplotlib
- pip install seaborn
- pip install statsmodels
Launch Jupyter Notebook:
- jupyter notebook


## Usage: how to run the project
Follow along with the "[Global Superstore Dataset](./data/Global_Superstore.csv)" included in the Data folder.
1. Open the main notebook ('project1.ipynb')
2. Run each cell sequentially to reproduce the analysis
3. Visualisations and results will be generated for you
